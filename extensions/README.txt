Bypass Browser Extensions Directory
===================================
Author: Chirag Chanchal (chiragchanchal2345@gmail.com)
Copyright (c) 2026 Chirag Chanchal | Open Source (MIT)

Place unpacked Chrome or Firefox extension folders here.
Any folder containing a valid "manifest.json" will be automatically loaded
when Bypass Browser starts.

You can also install extensions at runtime using the 🧩 button on the toolbar:
- Load Unpacked Extension (Folder)...
- Install Extension (.crx / .xpi / .zip)...
